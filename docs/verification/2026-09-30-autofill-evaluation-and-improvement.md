# 招聘表单改进实施验证报告

日期：2026-09-30

工程改动已实施：规则优先、现有模型兜底、少量剩余项交给人工。没有引入 embedding、向量检索、专用模型部署或多供应商路由。固定样本、可复现的本地执行回归及前后报告已经保存；人工标注审核、真实模型性能和真人检查用时尚未完成。

## 已实施的变化

- 增加扩展内部只读会话结果，包含真实阶段、是否结束、自动与辅助完成数以及逐字段状态。不给普通网页暴露接口，也不包含个人资料值。浏览器测试等待结构化状态，不再解析面板文案。
- 规则确定的字段先填。已明确缺资料保持空白；没有配置模型时，含义未知字段归入人工处理，不误报为个人资料缺失。
- 已验证的事实绑定在选项判断中保持稳定。模型不能换到其他事实或经历；同组先前绑定的记录也作为约束传入。用户明确更正含义时清除旧绑定。
- 明确模块保留完整相关经历并减少无关事实；含义不清时保留完整资料。字段定义仍完整可见，没有 Top-K 截断。模型返回原快照中存在但本次输入未提供的事实 ID，也会被拒绝。
- 执行不支持、已知日期精度不足和普通文本格式失败直接交给人工。读取选项未产生新证据时不重复请求。现有单次 20 秒请求上限与恢复预算保持。
- 修复 UD 多选、已展开或复用弹层、树选项观察和叶子选择，以及 ATSX 已选标签读回。排除弹层内部控件的重复扫描，拒绝模糊弹层归属、父节点代替叶子和错误父路径。
- Moka 中观察到的 SD Select 容器识别为选择控件；完整操作尚未适配时交给人工，避免把搜索输入当作普通文本写入并虚报选择完成。
- 修正“开始工作年月”与某段经历开始日期的混淆。无匹配证据时不返回定义表头部的任意候选。
- 修复任务面板自动收起后按钮状态不一致，增加补填入口和输入的可访问名称，更新浏览器测试以使用当前补填流程。显示填写状态，移除交互预览字样；保存资料与网页执行结果继续分别反馈。

## 留出结果与尚未完成的测量

AvePoint 的离线事实绑定准备结果为 16 / 16 个预期自动实例。原生控件结构复现验证姓名、电话和邮箱写入，以及已有岗位保护；没有明确标签关联的单选仍交给人工。没有根据该留出问题追加选项标签规则；后续若据此修复，应将它转入开发集并换新的留出来源。

真实网站整页填写流程未运行，因此不声称三个网站全部可用或达到某个跨站覆盖率。Moka 的 SD Select 没有完整操作适配。人工标注审核、真人检查时间、真实模型语义准确率与 API 成本仍未测量。工程替身只证明协议与流程，不能作为真实模型效果。结构化 `modelRequests` 统计逻辑决策调用次数，服务内部重试可能对应更多实际 API 请求。

## 复现方式

- 完整检查：`npm test`、`npm run lint`、`npm run build`、`npm run test:form-fill:browser`。
- 规则固定集：`npm run eval:fields -- --output /tmp/field-report.json`。
- 真实模型固定集：`npm run eval:fields -- --mode model --config /absolute/path/llm-config.json --output /tmp/model-report.json`。配置使用现有 `LLMConfig` 格式；配置文件和凭据不进入仓库，无效配置也不回显内容。
- 浏览器结果文件：设置 `JOB_APPLYMATE_REPORT_PATH` 为输出路径。可用 `JOB_APPLYMATE_TEST_FILTER=UD` 做针对性回归；完整验收不设置过滤条件。
