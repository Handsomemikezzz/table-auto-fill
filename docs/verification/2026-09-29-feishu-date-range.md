# 飞书招聘起止时间诊断

## 实页观察

用户提供的小鹏招聘申请页使用两个普通文本输入框。共享字段名为 start_end_time，容器为 throne-biz-date-range-picker-wrapper；输入框没有日期 type 或格式 placeholder。输入框到共享字段标签之间有八层以上包装。

使用用户给出的 2018.8 和 2022.6，失焦后网页显示 2018-08、2022-06，填完两端后“请填写完整时间”提示消失。没有提交申请。

## 复现和修复

按实际结构建立本地 React 受控表单，修复前复现：

- 教育两端都被识别为 graduationDate，工作两端都被识别为 endDate。
- 开始框误用了结束日期；另一端可能因为经历绑定失败而空着。
- 2018.8 被网页转换成 2018-08 后，严格字符串比较返回 unverified。

修复包括：

- 在多控件边界内向上读取深层共享标签，分别识别两个端点。
- 明确端点标签优先于共享 start_end_time 名称。
- 读取左右分栏中的模块标题，区分教育和工作经历。
- 日期字段按相同精度的日期值验证；普通文本仍严格比较，不允许年月被补成具体日后计成功。
- 两个日期端点的学习签名分开，避免重用同一条纠错记录。
