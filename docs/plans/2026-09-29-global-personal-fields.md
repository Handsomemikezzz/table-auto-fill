# 全局个人补充资料

按使用反馈，填写面板不再提供“记住本网站此字段的含义”。本次含义确认仅影响当前任务；旧的网站纠错和控件经验保留为兼容数据，不再参与默认填写，也不再新增此类记录。

## 保存与填写

- 年龄、作品链接、期望城市、语言能力分别保存在 `personal.age`、`personal.portfolioUrl`、`personal.preferredCities`、`personal.languageSkills`。
- 其他补充信息保存在 `personal.additionalFields`，按名称和真实内容复用，不保存域名、表单指纹或网站编码。
- 资料设置页的“个人基本信息”统一维护这些字段；手动资料助手也会展示已保存值。
- 已有资料优先通过规则匹配，未知表达由模型兜底。明确缺少的资料保持空白，不再列为必须处理的失败；用户可按需选择“补充个人资料”。
- 面板提供“保存并填写”和“只保存资料”。资料保存与网页执行分别反馈；连续新增不同字段不会因整个资料版本变化而失败，同一字段发生并发修改则要求核对。
- 旧 `additionalFacts` 和已保存的自定义答案仍可读取，新数据和备份使用个人资料中的结构。明确更新或清空的个人字段优先，旧答案不会重新覆盖它们。

## 验证

新增回归覆盖跨域复用、缺资料不发模型请求、不阻塞其他字段、重复保存更新同一项、并发保存不同项、旧资料兼容，以及补充信息的备份导入导出。

浏览器使用两个不同源的本地表单：在第一个页面补充年龄、作品链接和推荐方式，在第二个页面无模型请求地自动填写；未提供的期望城市和语言能力保持空白。
