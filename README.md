Job ApplyMate 是一款适用于 Chrome 和 Edge 的求职申请搭档，用于集中管理求职资料、识别招聘表单并快速填入个人信息、教育经历、实习项目和简历文件。

## 功能说明

| 功能 | 说明 |
|---|---|
| 资料管理 | 保存基本信息、年龄、作品链接、期望城市、语言能力、其他个人信息，以及教育经历、实习经历、项目经历、技能和证书；本科与研究生教育经历独立管理 |
| 填写当前页面 | 通过 DOM 识别控件并按本地规则填写；填写后读回验证，无法确定的字段交给用户处理 |
| 一个任务面板 | 显示理解、匹配、填写检查阶段；分别统计自动完成、辅助完成、保留原值和跳过项；随时停止 |
| 分类待处理 | 日期未确认时重新检查；下拉未选中时定位原控件；仅在缺事实时补充资料 |
| 日期与记录约束 | 保留真实日期精度，同一逻辑经历组绑定同一记录，起止日期整体检查 |
| 局部填写 | 在“更多”中框选某一区域，复用同一决策协议，通过 DOM 识别填写区域 |
| 信息浮窗 | 直接固定在招聘网页内，可拖动并记住位置；先聚焦网页输入框，再点击单条资料完成写入，失败时自动复制 |
| 多简历库 | 保存多份面向不同岗位的简历及其独立解析资料；保留原文件名，并用插件内分类区分；当前资料与可选附件分别选择 |
| 简历解析 | 支持 PDF、DOCX、Markdown、TXT 和结构化 JSON |
| JSON 备份 | 版本化导入、导出，导入前验证格式并显示摘要 |

## 快速安装

### 普通用户安装

如果你只是想使用插件：

1. 点击当前仓库右侧的 Releases 页面下载最新版，或直接下载仓库中的 [`release/job-applymate-extension.zip`](release/job-applymate-extension.zip)。
2. 先将压缩包解压到本地任意文件夹。
3. 打开 Chrome 或 Edge 的扩展程序管理界面。
4. 开启页面内的“开发者模式”。
5. 点击“加载解压缩的扩展”。
6. 选择刚才解压出来的扩展目录。
7. 将“Job ApplyMate”固定到浏览器工具栏，方便使用。

浏览器不能直接加载 `.zip` 压缩包，必须先解压，再加载解压后的目录。

## 如何使用

### 配置个人资料

1. 点击浏览器工具栏中的插件图标。
2. 点击“资料设置”进入设置页。
3. 在同一页依次填写基本信息、教育经历、实习与项目、更多资料和自定义信息；页内目录可快速定位，无需切换标签。
4. 点击底部固定栏的“保存全部资料”，右上角出现“保存成功”后即可关闭页面。数据备份可在页尾展开。

本科和研究生请分别添加教育经历。每条可独立保存学校、学院、专业、专业类别/一级学科、学习形式、学历层次、学位、入学与毕业时间。招聘页面明确写出“本科”或“研究生”时，插件会按学历层次匹配对应经历，而不是只按保存顺序填写。
缺少学院、学习形式、学位或日期精度时保持缺失，不用另一条经历或默认值补造。

填写完全基于网页 DOM、本地字段规则和已保存资料，不需要配置模型。未知字段可在任务面板中确认含义，或使用资料浮窗手动填写。

### 导入简历

在“简历库”中添加文件：

- JSON、PDF、DOCX、Markdown、TXT：使用本地规则解析；结构化 JSON 直接映射资料。
- 添加前可填写“产品岗”“运营岗”等分类。分类只在插件里显示，上传到招聘网站时仍使用文件的原始名称。
- 可重复添加多份简历，并在列表中修改分类或删除文件。
- 删除简历会立即保存；再次添加同一个原文件时更新原条目，不会生成重复副本。
- 每份简历独立保存解析资料；新增简历不会覆盖其他简历或已有的默认资料。

解析完成后会显示资料更新草稿。勾选需要更新的项目后确认保存；已有资料的覆盖项默认不勾选。附件先独立保存在简历库。

### 填写网申表单

1. 打开申请表单，在弹窗确认“当前资料”（默认通用资料）。
2. 按需选择附件；选择附件不会切换事实来源。岗位资料在“更多”中选择。
3. 点击“填写当前页面”，在页面任务面板查看进度或停止。iframe 内的字段共用主页面任务面板。
4. 逐项处理待办：重新检查、在网页中选择、确认字段含义或经历、补充事实、本次跳过。
5. 未提供资料的字段保持空白，单列为“无资料留空”，无需逐项处理。可点击“补充个人资料（可选）”，选择“保存并填写”或“只保存资料”。
6. 保存到个人资料的信息可在不同网站复用，也可在“个人基本信息”中修改或删除。年龄、作品链接、期望城市和语言能力支持常见名称匹配；其他信息按已保存的名称匹配，无法确定的表达交给用户确认。“更正理解”仅用于本次匹配。
7. 面板“更多”提供可恢复修改的撤销和主动导出脱敏诊断。用户之后修改的值会保留。

自动填写使用本次事实快照，按本地规则匹配字段并执行控件操作。单个字段或模块失败会留在待办，其他项目继续。仅使用已有事实和真实选项；日期精度不足时不会默认补成 1 日。

页面跳转后需再次启动填写；插件不会提交申请。自动完成率和准确率需用真实标注样本评估，本地回归不能代替跨站效果评测。

### 使用信息浮窗

信息浮窗适合逐个处理自动填充未识别的特殊字段。写入操作必须按以下顺序完成：

1. 保持网申页面打开，点击浏览器工具栏中的插件图标。
2. 点击“打开资料”，资料面板会直接固定在当前招聘网页右侧；可拖动顶部调整位置，插件会记住位置。
3. 在同一网页中先点击需要填写的输入框、文本域或下拉框，使光标停留在该字段中。
4. 在固定浮窗中展开对应的教育、实习、项目或自定义信息。
5. 点击具体字段或整条自定义信息，例如“学校”“专业”“公司”“岗位”，插件会把该字段值写入刚才聚焦的网页输入框。
6. 浮窗滚动页面时仍保持固定；若被网站重绘误删会自动恢复。页面不允许直接写入时，内容会自动复制到剪贴板，可手动粘贴。



### 只填某一区域

弹窗“更多 → 只填某一区域”支持拖动选区，按 `Esc` 取消。选中区域使用与整页填写相同的事实、规则匹配和验证流程。

### 本地备份

设置页的“数据备份”提供 JSON 手动导入和导出。备份包含个人资料、简历原文件和填写设置。旧版记录仅作为兼容数据保留，不再提供记录管理。

- “导入完整数据”：选择以前导出的 JSON，检查通过后确认覆盖本地资料。
- “导出完整数据”：下载当前全部资料的 JSON 备份。

旧版本导出的 JSON 仍可直接导入；旧备份中的模型配置、API Key 和 WebDAV 配置会被忽略。新增的个人补充资料会随新的完整备份保存。

完整备份包含个人资料和简历文件，请妥善保管。新备份不包含模型或 WebDAV 配置；扩展启动时会清理遗留凭据、模型缓存和同步状态。

## 安装与开发
### 开发与本地构建

如果你需要自行修改代码、重新构建，才需要准备下面的环境：

- Chrome 或 Edge 116 及以上版本
- Node.js 20.19 及以上，或 Node.js 22.12 及以上
- npm

推荐安装最新的 Node.js LTS 版本。

### 一键安装并构建

下载项目后，在项目根目录运行对应脚本：

- macOS：双击 `一键安装依赖.command`
- Windows：双击 `一键安装依赖.bat`

脚本会依次完成：

1. 检查 Node.js 和 npm。
2. 使用 `npm ci` 安装锁定版本的依赖。
3. 运行全部自动化测试。
4. 构建可加载的 `dist/` 目录。


### 常用命令

```bash
npm test
npm run build
npm run lint
npm run dev
```

- `npm test`：运行全部自动化测试。
- `npm run build`：类型检查并生成 `dist/`。
- `npm run lint`：运行静态代码检查。
- `npm run dev`：启动 Vite 开发服务，扩展调试仍需构建后加载 `dist/`。

## 数据说明

- 默认数据保存在浏览器扩展的 `chrome.storage.local`。
- JSON 导入文件上限为 20 MiB。
- 手动备份文件为明文 JSON，可能包含个人信息和简历。
- 卸载扩展或清除扩展数据前，建议先导出完整备份。

### 从简历自动准备资料

点击“从简历一键解析建档”，或在简历库拖入文件。现在支持扫描 PDF 和 PNG、JPG、JPEG、WebP 图片；文件上限 20 MB。文字 PDF 直接读取，扫描内容在本地使用中英文 OCR 识别。

识别文字会由本地规则整理为预填写草稿。先核对联系方式，再按需展开经历和其他资料；没识别到的信息可稍后补充。已有值默认保留，也可以逐项采用新识别值。确认保存后，就能回到申请页使用现有的一键填写。

可以停止识别、重试、暂存草稿或查看原文。OCR 和资料整理都在浏览器内完成。详见 [本轮验证说明](docs/verification/2026-10-01-resume-ocr-prefill.md)。

资料建档同时收集获奖与荣誉、论文与著作、语言能力、证书与资格、专利、校园与志愿经历，以及其他补充资料。语言考试保留成绩与日期，论文保留署名、期刊/会议和发表状态；未知内容留空。设置页的“更多个人资料”可按需添加和修改，网页信息浮窗可点选这些内容填写。规则解析会把相关章节原文保存在补充资料中，便于人工核对。新增信息支持简历版本和备份恢复，兼容旧资料。详见 [扩充资料验证](docs/verification/2026-10-01-supplemental-profile.md)。

论文可以出现在“项目研究”等混合章节中。解析后会检查原文的 Paper、论文及 DOI 线索，补齐遗漏条目；只有会议名的研究内容可在核对页点击“加入论文与著作”。展览不会仅因会议名自动归为论文，未注明的发表状态和日期留空。详见 [混合章节论文识别验证](docs/verification/2026-10-01-publication-recovery.md)。
